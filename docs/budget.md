# Бюджет на жизнь и напоминания

## Модель

- **Период:** с дня `period_start_day` по день перед следующим таким же (по умолчанию 25-е → 24-е)
- **Лимит на жизнь:** 50 000 ₽ за период (50% от выплаты 25-го)
- **Не входят в лимит:** дом, инвест, благ, переводы на счёт «сбережения»
- **Входят в лимит:** все остальные расходы, включая **фин** (налоги, долг)

## Лист «Бюджет»

### Параметры (A:B)

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| life_budget | 50000 | Бюджет «на жизнь» за период |
| period_start_day | 25 | День начала периода |
| morning_summary_hour | 9 | Час утренней сводки (МСК) |
| reminder_hour | 22 | Час вечернего напоминания (МСК) |
| reminder_timezone | Europe/Moscow | Часовой пояс |
| excluded_categories | дом,инвест,благ | Исключения из лимита |
| excluded_accounts | сбережения | Счета-исключения |

### Конструктор (формулы)

**Под параметрами (с строки 10, A:B):** категория и среднее только по циклам с суммой > 0 (`AVERAGEIF`).

**Справа (с колонки F, после зазора C–E):** матрица «категория × цикл» — 6 циклов от текущего к более старым. Строка «Итого» — сумма по колонке.

**Цифры** в ячейках обновляются сами при новых тратах на `YYYY-MM` (формулы Sheets).

**Пересборка** заголовков и диапазонов дат:
- автоматически при правке `period_start_day` (ячейка значения в колонке B);
- каждый день в 00:00 (МСК) — чтобы новый цикл подхватывался без ручного запуска;
- вручную: `refreshBudgetDashboard()`.

## Формулы лимита «на жизнь»

| Показатель | Формула |
|---|---|
| Остаток | life_budget − потрачено_на_жизнь |
| На сегодня | остаток / дней_осталось |
| Идеальный темп/день | life_budget / дней_в_периоде |
| Отклонение от темпа | (темп × день_периода) − потрачено (+ = экономите) |
| Дней воздержания | при перерасходе: ceil(превышение / идеальный_темп) |

## Команды бота

| Команда | Описание |
|---|---|
| `/bud` | Лимит «на жизнь» и темп на сегодня |
| `/cur` | Траты по категориям за **текущий бюджетный цикл** |
| Утро 9:00 | Автоматическая сводка «Доброе утро! Бюджет на сегодня» |
| Вечер 22:00 | «Пора занести траты» + краткий блок бюджета |

`/mon` — календарный месяц; `/cur` — цикл по `period_start_day`.

## Помесячные листы

Операции хранятся на листах **YYYY-MM**:

- **A–F** — операции (заголовки в строке 1, данные с 2)
- **I–J** — сводка месяца (QUERY по категориям растёт вниз в колонках I–J)

Бюджет `/bud` и `/cur` при необходимости читают **два** месячных листа.

Переводы `> сбер` / `< сбер` на бюджет **не влияют** — см. [savings.md](savings.md).

## Настройка

1. Обновите `Code.gs` в Apps Script
2. Запустите **`resetBudgetSheet()`** или **`refreshBudgetDashboard()`**
3. Запустите **`resetCategories()`** при смене категорий
4. Укажите **`ALLOWED_CHAT_ID`** в свойствах скрипта (для напоминаний)
5. Запустите **`installAllTriggers()`**

## Проверка вручную

- `refreshBudgetDashboard()` — пересобрать конструктор на листе «Бюджет»
- `sendMorningBudgetSummary()` — утренняя сводка
- `sendDailyReminder()` — вечернее напоминание
- `/bud`, `/cur` в Telegram
