# Категории расходов и доходов



Короткие названия — удобнее вводить в Telegram одной строкой.



## Категории расходов



| Категория | Было | Что сюда относить | В лимите «на жизнь»? |

|---|---|---|---|

| **еда** | продукты | Продукты из магазина, доставка | да |

| **кафе** | рестораны | Кафе, рестораны, готовая еда | да |

| **транс** | транспорт | Метро, бензин, такси, билеты | да |

| **дом** | жильё | Аренда, коммуналка | **нет** |

| **быт** | — | Гигиена, бытовая химия, косметика (товары) | да |

| **мед** | здоровье | Врачи, аптека, анализы | да |

| **крас** | красота | Салон, барбер, маникюр, СПА | да |

| **подпис** | подписки | Интернет, телефон, стриминг, VPN, софт | да |

| **отдых** | развлечения | Кино, игры, хобби | да |

| **путеш** | туры, путешествия | Экскурсии, музеи, визы, поездки | да |

| **одежда** | — | Одежда, обувь | да |

| **техн** | техника | Электроника, гаджеты | да |

| **подар** | подарки | Подарки другим людям | да |

| **инвест** | инвестиции | Брокер, вклады, крипта | **нет** |

| **благ** | благотворительность | Пожертвования | **нет** |

| **фин** | финансы | Налоги, погашение долга | да |

| **привыч** | привычки | Курение, алкоголь | да |

| **прочее** | — | Всё остальное | да |



## Категории доходов



| Категория | Было | Что сюда относить |

|---|---|---|

| **зп** | — | Зарплата (10-е и 25-е) |

| **фрил** | фриланс | Фриланс, подработки |

| **возврат** | — | Возвраты, кэшбек |

| **подар** | подарки | Полученные подарки (деньги) |

| **инвест** | — | Дивиденды, купоны, продажа активов |



## Поездки



**Правило: категория = что купили, комментарий = поездка.**



```

1200 кафе анталия

800 еда анталия

5000 дом анталия

2500 путеш анталия

```



## Примеры



```

850 еда

450 кафе

1500 крас

800 подпис

5000 благ

10000 инвест

+100000 зп

+15000 фрил

+5000 инвест дивиденды

+500 возврат

```



## Команды



```

/cat  — список категорий

/bud  — лимит на сегодня

/cur  — траты за текущий цикл

/sav  — баланс сбережений

/mon  — итог за месяц

/tod  — итог за сегодня

/hel  — справка

```



## Переводы на сбережения



Не путать с категорией `инвест`:



```

25000 > сбер

5000 < сбер

```



Подробнее: [savings.md](savings.md)



## Применить набор



1. Обновите `Code.gs` в Apps Script

2. Запустите **`resetCategories()`**

3. Запустите **`resetBudgetSheet()`** (обновит исключения: дом, инвест, благ)

4. Проверьте `/cat`



Подробнее о бюджете: [budget.md](budget.md)
