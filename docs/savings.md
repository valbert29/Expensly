# Переводы карта ↔ сбережения

Переводы **не являются** расходами или доходами и **не влияют** на `/tod` и `/bud`.

В **остатке месяца** (`/mon` и сводка на листе) учитываются:

```
остаток = доходы − расходы − на_сбер + со_сбера
```

Сами суммы «Расходы» и «Доходы» по категориям **не меняются**.

## Формат ввода

| Действие | Пример |
|---|---|
| На сбережения | `25000 > сбер` |
| Обратно на карту | `5000 < сбер` |
| С комментарием | `25000 > сбер отложил с зп` |
| Баланс | `/sav` |

Синонимы: `сбер`, `сбережения`.

## Команда `/sav`

Показывает:

- текущий баланс сбережений
- последние 5 переводов

## Лист «Счета»

**Справочник (строки 1–4)**

| A Счёт | B Описание | C По умолчанию | D Баланс |
|---|---|---|---|
| сбережения | … | FALSE | формула из журнала |

**Журнал переводов (с строки 8)**

| A Дата | B Направление | C Сумма | D Комментарий |
|---|---|---|---|
| … | на сбер / с сбер | … | … |

Баланс в колонке D считается автоматически: пополнения минус снятия.

## Поведение переводов

### `25000 > сбер` (карта → сбережения)

- запись в журнал «Счета»
- баланс сбережений **+25000**
- расходы/доходы месяца **не меняются**
- **остаток** месяца уменьшается на 25000

### `5000 < сбер` (сбережения → карта)

- запись в журнал «Счета»
- баланс сбережений **−5000**
- расходы/доходы месяца **не меняются**
- **остаток** месяца увеличивается на 5000
- баланс карты **не ведётся** — только накопления

Если снять больше, чем на счёте, бот **предупредит**, но запись сохранит (баланс может уйти в минус).

## Перевод vs `инвест`

| | Перевод `> сбер` | Запись `10000 инвест` |
|---|---|---|
| Куда пишется | лист «Счета» | месячный лист |
| В расходах месяца | **нет** | **да** (но не в лимит «на жизнь») |
| В остатке месяца | **да** (−) | косвенно (как расход) |
| Баланс сбережений | **да** | **нет** |
| Смысл | переместил деньги на накопительный | учёт распределения дохода |

## Настройка

1. Обновите `Code.gs`
2. Запустите **`setupAccountsSheetLayout()`** (или `initializeSpreadsheet()` при чистой таблице)
3. Для текущего месяца — **`refreshMonthSheetSummary()`** (обновит формулы сводки)
4. Проверьте: `25000 > сбер`, `5000 < сбер`, `/sav`, `/mon`
